# THE FRAY

Экшен-рогалик для Telegram. Один HTML-файл, three.js с CDN, никакой сборки.

**Играть:** https://t.me/the_fray_game_bot
**Сайт:** https://schopsche.github.io/-the-fray/

---

## 1. Репозиторий и хостинг

GitHub Pages подходит идеально: бесплатно, отдаёт по HTTPS, а Telegram другого
и не принимает.

1. Создай репозиторий, например `the-fray`. Публичный — для бесплатных Pages это обязательно.
2. Положи в корень `index.html` (это и есть игра).
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**
4. Через минуту-две адрес будет такой:
   `https://schopsche.github.io/-the-fray/`

Открой его в обычном браузере и убедись, что игра запускается. Вне Telegram
всё работает, кроме сохранения рекорда — оно живёт в Telegram CloudStorage.

Обновление потом — обычный коммит в `index.html`. Pages пересоберёт сам за минуту.

## 2. Бот и мини-приложение

Всё в переписке с [@BotFather](https://t.me/BotFather).

**Создать бота**

```
/newbot
```
Дальше он спросит имя и юзернейм (юзернейм обязан заканчиваться на `bot`).
В ответ придёт токен вида `1234567890:AAH...`. Это пароль от бота — не публикуй
его и не коммить в репозиторий.

**Привязать игру**

```
/newapp
```
Выбираешь бота, вставляешь адрес с Pages, задаёшь название, описание и картинку
640×360. После этого игра открывается по прямой ссылке:

```
https://t.me/твой_бот/имя_приложения
```

Ссылку можно кидать в чаты — открывается в один тап, без диалога с ботом.

**Кнопка у поля ввода**

```
/setmenubutton
```
Выбираешь бота, вставляешь тот же адрес, пишешь надпись — например `Играть`.
Теперь у всех, кто открыл переписку с ботом, слева от поля ввода будет кнопка запуска.

Если запустишь `bot.py` (см. ниже), эта кнопка настроится сама, вручную делать не нужно.

## 3. Бот на Python (необязательно)

Строго говоря, для запуска игры бот не нужен: хватает прямой ссылки и кнопки меню.
Бот нужен, когда хочется приветственное сообщение, команды или приём результатов из игры.

Зависимостей нет, только Python 3.

```bash
BOT_TOKEN=1234567890:AAH... \
APP_URL=https://schopsche.github.io/-the-fray/ \
python3 bot.py
```

Что делает: отвечает на `/start` сообщением с кнопкой запуска игры, ставит
команды бота и настраивает кнопку меню, а также принимает данные, если игра
однажды начнёт их слать через `Telegram.WebApp.sendData`.

Пока скрипт запущен на твоей машине — бот отвечает. Закроешь терминал — перестанет.
Для круглосуточной работы нужен любой дешёвый VPS и `systemd`, либо хостинг вроде
Railway или Fly.io. Прямая ссылка и кнопка меню при этом работают всегда,
независимо от бота.

**Токен не клади в репозиторий.** Он читается из переменной окружения именно поэтому.
Если случайно закоммитил — немедленно `/revoke` у BotFather и заведи новый.

## 4. Как мы дальше правим игру

У меня между сессиями не сохраняются ни файлы, ни память, поэтому рабочий цикл такой:

1. Кидаешь мне ссылку на репозиторий или на сырой файл
   (`https://raw.githubusercontent.com/Schopsche/-the-fray/main/index.html`).
2. Я скачиваю текущую версию, вношу правки, отдаю готовый файл.
3. Ты коммитишь.

Так у нас всегда одна версия правды — та, что в репозитории, — и не бывает
расхождений из-за того, что я правлю устаревшую копию.

## Где что искать в коде

Весь код в `index.html`, разделён на пронумерованные блоки:

| Блок | Что внутри |
|---|---|
| `UI` | все тексты интерфейса, русский и английский |
| `CFG` | баланс: здоровье, урон, темп волн, откаты |
| `PLACES` | три локации и их цвета |
| `ENEMIES`, `BOSS` | типы врагов и их характеристики |
| `FOE_LOOK` | внешность врагов: комплекция, костюм, галстук, шляпа |
| `UPGRADES` | усиления, которые падают бонусами на карту |
| `HEROES` | шесть персонажей |
| `SHOP` | товары лавки |
| `MODEL` | геометрия персонажа, разобранная на части из `chel.obj` |

Управление: движение — палец в любом месте экрана или WASD, рывок — Shift,
Волна — пробел, пауза — Esc.
